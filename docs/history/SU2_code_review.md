## 已核实的正确性

- `quaternion` 只除以正数，保留反足区别；负叉积乘法与 `+iσ` 约定一致。齐次射线只承担精确代数表示，文档明确其链级含义是单位代表。
- `hemisphere_safe` 的支持子集枚举正确。最小非负依赖的核必为一维：若有另一独立核向量，可从严格正依赖沿它移动到某分量首次为零，得到更小支持，矛盾。代码检查所有这样的支持，不会漏掉“没有反足顶点，但凸包仍包含原点”的情形。
- `edge_chain`、`face_chain`、`tetrahedron_chain` 保留有序项，只消去相邻重复；普通降秩和非相邻重复链仍保留。`_cone` 严格比较精确矩阵秩，使用理论规定的首个可用候选和有界搜索。
- 另行用整数系数 Counter 检查了 **5 组三角形**的边界与左等变，以及 **6 组四面体**的边界、左等变和所有输出项的合法性，均严格相等；另有 **4 个凸包判定基准**全部通过。样本覆盖中心反足、非相邻重复、无反足的三点正依赖、秩三的四点正依赖、普通安全降秩。未将反向链作负链合并。
- 因此主证明中五个 T 的边界逐项抵消适用于当前代码表示；现有异常输入的数值五边形检查与该证明相符。没有把原始 `D=0` 全部当作零体积。
- `FACE_PAIRS=(01,02,12,23,13,03)` 与原文角 Gram 矩阵逐项匹配，对应实际棱 `(23,13,03,01,02,12)`。八个 Li₂ 参数、角乘积项、r0、r1、r2、判别式及 Arg/常数项均核对无误。原文依据是 [Murakami v4，定理 1.1、式 (1.2)、式 (2.1)、引理 2.2](https://arxiv.org/pdf/1011.2584v4)。
- 代码使用未经单位化的 Gram 矩阵求逆是正确的：正对角缩放在 `−Hij/√(HiiHjj)` 及 `det(G)=1/(det(Γ)∏Hii)` 中抵消。精确 `det Q` 提供取向，合法降秩项的三形式积分为零。

## 重要发现与修复证据

### 1. 大整数 level 原先造成 O(1) 相位错误：已修复并复测

位置：[su2_omega.py:286](../../src/su2_omega.py#L286)，`omega_quaternions` 的工作精度与最终指数。正交校准输入

```python
x, z = (0,1,0,0), (0,0,0,1)
omega_quaternions(x, z, x, k=16*10**80, dps=50)
```

严格体积为 π²/8，故正确结果为 1。原实现返回约 `−0.7492683618+0.6622665037j`，误差 `1.8704375754`，原因是指数前乘 k 将固定精度体积误差放大。

当前实现按 k 的位数同时增加体积和指数精度。本审查独立复测：与 1 的误差为 `1.53052284033e−69`。新增精确周期回归有必要保留。

### 2. 极小体积原先通过范围检查却严重相对失真：已修复并复测

位置：[su2_omega.py:198](../../src/su2_omega.py#L198)，`oriented_volume` 的消去精度预算。令

```python
eps = Fraction(1, 10**100)
gs = [(1,eps,0,0), (1,0,eps,0), (1,0,0,eps)]
# 从 IDENTITY 累计乘法取得四个顶点，再调用 oriented_volume。
```

该体积为 `eps**3/6 * (1+O(eps))`。原实现 dps=50 时，计算值与 `eps**3/6` 的比为 `2.166233251037795e25`；dps=100 时为 1 附近。原来的角 Gram 行列式预算不能独自控制最终体积的消去。

当前实现加入由单位顶点给出的严格下界 `|V|≥|D_unit|/6` 所需位数。独立复测 dps=50 的相对误差为 `8.69614615883e−77`。这是有依据的精度预算和回归证据；仍不是任意输入的区间算术误差证明，文档应继续保留该限制。

### 3. mpmath 非有限坐标原先静默变为零：已修复并复测

位置：[su2_omega.py:16](../../src/su2_omega.py#L16)，`_fraction` 的 `mp.mpf` 分支。原来直接读取 `_mpf_` 中的零 mantissa，使

```python
quaternion((1, mp.nan, 0, 0))
```

静默返回单位元；`mp.inf`、`−mp.inf` 同样发生。当前先检查有限性。本审查再次运行这三个输入，均正确抛出 `ValueError`。

### 4. 高精度矩阵被固定 40 位转换截断：已修复并复测

位置：[su2_omega.py:257](../../src/su2_omega.py#L257)，`matrix_quaternion` 原先的固定 `mp.workdps(40)` 转换及分量求和。

最小复现：在 `mp.workdps(100)` 下构造轴角 `.7,.8,.9` 的三个四元数，并由同一组分量构造矩阵

```python
[[q0 + 1j*q3, q2 + 1j*q1],
 [-q2 + 1j*q1, q0 - 1j*q3]]
```

调用 `omega_su2(*matrices,dps=80)` 与 `omega_quaternions(*qs,dps=80)`，原误差为 `5.25713791105943467119411798791e−44`；第一个矩阵提取出的精确射线也已不等于原始坐标的精确射线。提高输出 dps 无法恢复入口丢失的信息。

当前从原 `mp.mpc`/`complex` 实虚部分别提取 Fraction，再以 Fraction 做四元数分量的和差，连 SU(2) 容差验证也使用精确有理式。本审查复测上述例子：**三个提取射线均与原射线精确相等，两个 80 位 phase 入口之差为 0**。新测试已覆盖同一高精度输入的矩阵/四元数双入口。
