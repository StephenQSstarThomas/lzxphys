一、已有进度：应当复核的计算基线

讨论 1+1 维玻色体系、通常整数 level k 的 SU(2) 规范反常。目标是它在对称缺陷 F-move 中的标量相位 omega_k(g1,g2,g3)。不讨论 3+1 维 Witten 反常，不以计算整个 H^3(SU(2)^delta,U(1)) 为任务。

此前采用反厄米规范场 A、二维基本表示的普通迹 Tr，并固定

\[
I_4=-\frac{k}{8\pi^2}\operatorname{Tr}(F\wedge F),\qquad
I_3=-\frac{k}{8\pi^2}\operatorname{Tr}(A\wedge dA+\tfrac23A^3).
\]

在局部平坦场 A=h^{-1}dh 上，

\[
I_3=\frac{k}{24\pi^2}\operatorname{Tr}(h^{-1}dh)^3.
\]

写 h=x_0 I+i\boldsymbol x\cdot\boldsymbol\sigma，x_0^2+|\boldsymbol x|^2=1。选定 S^3 的取向后，

\[
\eta=\frac{1}{24\pi^2}\operatorname{Tr}(h^{-1}dh)^3
=\frac{dV_{S^3}}{2\pi^2},\qquad \int_{S^3}\eta=1.
\]

候选反常代表为

\[
\omega_k(g_1,g_2,g_3)=\exp\!\left(2\pi i k\int_{C(g_1,g_2,g_3)}\eta\right).
\]

C 的边和面必须由一致的预先选择定义。整数周期只保证在边界面已经固定后改变三维填充不改变相位；改变面约定一般引起二上链余边界。不能把这两种自由度混为一谈。

对一般位置，使用最短测地边、小测地三角面及其球面四面体填充。定义

\[
U_0=I,\quad U_1=g_1,\quad U_2=g_1g_2,\quad U_3=g_1g_2g_3.
\]

令 U_j=q_{j0}I+i\sum_{a=1}^3q_{ja}\sigma_a，q_j=(q_{j0},q_{j1},q_{j2},q_{j3})^T。再定义

\[
Q=(q_0,q_1,q_2,q_3),\qquad D=\det Q,\qquad \Gamma=Q^TQ.
\]

注意加号 i 的泡利矩阵约定下，乘法向量部分为

\[
(a_0,\boldsymbol a)(b_0,\boldsymbol b)
=(a_0b_0-\boldsymbol a\cdot\boldsymbol b,\,
a_0\boldsymbol b+b_0\boldsymbol a-\boldsymbol a\times\boldsymbol b).
\]

如果使用另一套四元数约定，必须同时调整取向，不能只改叉积符号。

当 D 不为零时，径向参数化

\[
x(t)=\frac{Qt}{|Qt|},\quad t_i\geq0,\quad \sum_{i=0}^3t_i=1
\]

给出

\[
V_{\rm or}=D\int_{\Delta_3}\frac{dt_1dt_2dt_3}{(t^T\Gamma t)^2},
\qquad
\omega_k=\exp(ikV_{\rm or}/\pi),
\]

其中 t_0=1-t_1-t_2-t_3，Delta_3 为非负 t_1,t_2,t_3 之和不超过 1 的区域。几何恒等式的关键是

\[
\det(x,\partial_1x,\partial_2x,\partial_3x)=D/|Qt|^4.
\]

令 T_i=(1/2)Tr(g_i)、T_{12}=(1/2)Tr(g_1g_2)、T_{23}=(1/2)Tr(g_2g_3)、T_{123}=(1/2)Tr(g_1g_2g_3)，则

\[
\Gamma=
\begin{pmatrix}
1&T_1&T_{12}&T_{123}\\
T_1&1&T_2&T_{23}\\
T_{12}&T_2&1&T_3\\
T_{123}&T_{23}&T_3&1
\end{pmatrix}.
\]

Gamma 确定 D^2，但不能丢掉 D 的符号。上述测地代表的一般位置表达可利用同时共轭对称性，用六个实迹和取向信息表示；这并不表示限制三个输入群元的自由度，也不保证异常点的分支选择仍严格共轭不变。

已有一个完全求掉积分、但还不是本次最终目标的收敛级数。给六条边赋非负整数 m_ij，设

\[
M=\sum_{i<j}m_{ij},\qquad s_i=\sum_{j\neq i}m_{\min(i,j),\max(i,j)}.
\]

则

\[
V_{\rm or}
=D\sum_{\{m_{ij}\geq0\}}
\frac{(M+1)!\prod_{i=0}^3s_i!}{(2M+3)!}
\prod_{i<j}\frac{[2(1-\Gamma_{ij})]^{m_{ij}}}{m_{ij}!}.
\]

其来源为

\[
t^T\Gamma t=1-\sum_{i<j}2(1-\Gamma_{ij})t_it_j,
\]

展开 1/(1-u)^2，并用

\[
\int_{\Delta_3}\prod_{i=0}^3t_i^{s_i}\,d^3t
=\frac{\prod_i s_i!}{(\sum_i s_i+3)!}.
\]

D 不为零时，Qt 在紧单纯形上不为零，因此展开一致收敛。靠近某些退化配置时收敛会很慢。这是数值交叉检查工具，不应把再次写出此级数当成完成闭式任务。

已有解析校准族：

\[
g_1=e^{i\alpha\sigma_1},\quad
g_2=i(\cos\alpha\,\sigma_2+\sin\alpha\,\sigma_3),\quad
g_3=e^{i\beta\sigma_1},\qquad 0<\alpha,\beta<\pi.
\]

其累计顶点为

\[
(1,0,0,0),\quad(\cos\alpha,\sin\alpha,0,0),\quad
(0,0,1,0),\quad(0,0,\cos\beta,\sin\beta).
\]

在此前的正取向约定下，

\[
V_{\rm or}=\alpha\beta/2,\qquad
\omega_k=\exp(ik\alpha\beta/(2\pi)).
\]

必须独立复核取向。度规给出的正体积不能未经检查就等同于任意坐标顺序下的有向三形式。

已有一个非特殊轴向例子的数值：

\[
g_1=e^{0.7i\sigma_1},\quad g_2=e^{0.8i\sigma_2},\quad
g_3=e^{0.9i\sigma_3}.
\]

直接三重积分得到

\[
D=0.25220893803677946,\quad
V_{\rm or}=0.07082150248008584,\quad
\omega_k=\exp(0.022543184393801173\,ik).
\]

该例的级数截断 M<=12 给出 V_or=0.07082148767853955，差约 1.48e-8。另一检查是 alpha=1.1、beta=2.0 的校准族给出 V_or=1.1。以上数值是待独立复核的基线，不是证明。

小群元校准：若 g_j=exp(i epsilon v_j dot sigma)，则候选代表应满足

\[
\log\omega_k
=\frac{ik\epsilon^3}{6\pi}
\boldsymbol v_1\cdot(\boldsymbol v_2\times\boldsymbol v_3)
O(\epsilon^4)
\]

在单位元邻域的零附近对数分支上成立。若采用 sigma/2 作为指数中的生成元，应重新换算系数。

二、可直接交给六个 agent 的共享提示词

你们是一组六名协作研究 agent。请独立复核上述基线，然后完成一般 SU(2) 对称缺陷三余循环的显式解析公式。已有回复只是研究起点，不是权威结论。发现错误应指出错误位置、给出修正及其对后续公式的影响。

输入为三个完全一般的 SU(2) 元素

\[
g_j=a_{j0}I+i\boldsymbol a_j\cdot\boldsymbol\sigma,\qquad
a_{j0}^2+|\boldsymbol a_j|^2=1,\qquad j=1,2,3,
\]

以及整数 k。每个元素有三个实自由度。不得把三个转轴固定、强制群元对易或只求一个两参数族后宣称已覆盖一般输入。

请明确区分：

1. 物理理论的反常系数 k 与群元依赖的函数 omega_k。
2. 一个选定的标量余循环代表与它的上同调类。
3. 一般位置上的分支解析公式与定义在全部 SU(2)^3 上的一致代表。

最终允许 Li_2、log、Arg、反三角函数和明确的分段条件。不能凭直觉宣称初等函数表达式不存在；若不提供不可能性证明，只能说当前使用了特殊函数。也不要把“解析表达式”误解为要求处处连续的非平凡标量余循环；这种连续性要求本身应先核查。

Agent 1：物理约定、几何构造与群元输入。

负责从反常多项式和有限规范变换出发，核对 I_4、I_3、eta、k 和最终相位的全部系数与正负号。明确使用基本表示迹还是归一化迹，禁止未解释地引入 k+2 等量子 level 位移。

从缺陷的两种融合说明四面体的四个面及其取向。检查累计乘积 U_j 的左右乘约定，并证明一般位置的径向填充给出何种余循环代表。给出从任意 g_j 到 Q、Gamma、D、边长和二面角的完整公式。提供一个固定的约定表给其他五人。

一般球面边长应核查为 ell_ij=arccos(Gamma_ij)。若 F_i 是与顶点 i 相对的面，则两个面的内二面角满足

\[
\cos\vartheta_{ij}
=-\frac{(\Gamma^{-1})_{ij}}
{\sqrt{(\Gamma^{-1})_{ii}(\Gamma^{-1})_{jj}}.
\]

这个角位于其余两个顶点组成的那条边上；必须给出“面编号对—实际边—Murakami 的 e_1,...,e_6”的准确对应表，不能把对边关系漏掉。

Agent 2：一般位置的有限二重对数闭式主路线。

负责使用并核对 Murakami 的二面角公式。必须把所有辅助变量都表达为 g_1,g_2,g_3 的函数：群元到迹、Gamma、二面角、复指数、辅助二次方程的根、Li_2 与 log 的参数、最后的有向相位。

不能只写“代入 Murakami 定理”。应把实际需要的完整表达式展开，并说明 sqrt、log、Li_2、Arg 的分支，体积模 2pi^2 的代表选择，以及 sign(D) 怎样进入相位。注意 Murakami 的辅助 q_0,q_1,q_2 不要与本说明的四维顶点 q_j 混名。先交一般位置上可执行的候选公式，再完善证明。

Agent 3：独立解析复算与公式简化。

优先使用 Murakami 的边长公式、直接积分化为特殊函数，或另一条原始文献路线进行独立复算。避免简单复述 Agent 2 的同一推导。

检查从边长到二面角、不同 Li_2 写法和不同根选择所得结果是否一致。找出两种表达的差是零、整数倍 2pi^2、还是代表改变引起的余边界；不得一概归入“模 2pi”。争取给出比主公式更便于代入的变量组或表达式。如果无法得到独立闭式，交付明确的等价性检查、可证明的局部展开和发现的分支问题。

Agent 4：全局分支、退化输入与三余循环证明。

负责核查一般位置的闭式能否扩展到全部输入，并说明合理的正则性要求。尤其区分 D=0 的不同原因：重复顶点、普通降维但 Qt 不为零、对跖点、原点落入顶点凸包、某个三角面跨越分支边界。

不得用“任取极限”解决全部退化情形。不同方向的极限可能对应不同面填充。需要给出预先固定、对所有共享边和面一致的选择规则，以及相应的分段值、补丁数据或有限分块算法；若算法不是有限特殊函数闭式，应明确它完成的是全局定义而非单一闭式。

必须证明所选代表满足

\[
\omega(g_2,g_3,g_4)\,
\omega(g_1,g_2g_3,g_4)\,
\omega(g_1,g_2,g_3)
=
\omega(g_1g_2,g_3,g_4)\,
\omega(g_1,g_2,g_3g_4).
\]

证明必须解释五个三维填充为什么有相容的面，并在取向求和后得到整数周期；只写“Stokes 定理所以成立”不够。异常点的分支赋值也应覆盖在论证中。

应满足归一化 omega(e,g,h)=omega(g,e,h)=omega(g,h,e)=1。如果改变代表，给出

\[
(\delta\beta)(g_1,g_2,g_3)
=\frac{\beta(g_2,g_3)\beta(g_1,g_2g_3)}
{\beta(g_1g_2,g_3)\beta(g_1,g_2)}
\]

以及 omega'=omega delta beta 的具体角色。不得把改变面引起的 beta 与同一固定边界的三维填充整数歧义混为一谈。

Agent 5：独立数值实现、误差与可复现校验。
