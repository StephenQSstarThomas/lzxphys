- [x] 实现：先累计顶点和 Gram，六边由 acos(dot)；a=-exp(-i l_opp) 用
  `-c_opp+I*sqrt(1-c_opp**2)` 构造以避免不必要的三角展开。

```python
raw = re(sum(polylog(2,z) for z in Z[:4])-sum(polylog(2,z) for z in Z[4:]))/2
raw -= sum((pi-l[j])*(pi-l[j+3]) for j in range(3))/2
raw -= pi*arg(-q2) + sum(l[j]*(pi-l[(j+3)%6]+im(Sigma[j])) for j in range(6))/2 + pi**2/2
phase = exp(-I*k*sign(detV)*raw/pi)
```

## Task 2: 符号恒等式与可积族

**Files:** `src/su2_symbolic.py`; `tests/test_su2_symbolic.py`。
**Consumes:** Task 1 的八个 Z、系数与符号式。
**Produces:** `reduce_real_dilog(terms)` 返回表达式、剩余项与恒等式记录；
`orthogonal_join_certificate(alpha,beta)` 返回带 0<|alpha|<pi、0<beta<pi 条件的符号证书。

- [x] RED：共轭抵消例、z=1/3 的 Euler 配对、±1/3 的 duplication 配对分别检查确切剩余项；
  证明域不满足时不强制化简。双圆弧测试代入 (pi/3,pi/4)、(-pi/3,pi/4)，期望 ±pi²/24。
- [x] 实现：相同参数先合并；主支单位圆内用 ReLi₂(z)=ReLi₂(conj z)；
  仅对 z 和 1-z 都处在开单位圆内使用 Euler；duplication 使用开单位圆条件。

```python
Li2(z)+Li2(1-z) = pi**2/6-log(z)*log(1-z)
Li2(z)+Li2(-z) = Li2(z*z)/2
integrate(cos(rho)*sin(rho),(rho,0,pi/2))*alpha*beta == alpha*beta/2
```

- [x] GREEN：运行完整符号测试；不可调用数值核验来放宽恒等式条件；提交。

**Files:** Create `src/su2_2t_geometry.py`; `tests/test_2t_geometry.py`。

- [x] RED：正交卦限有 72 室、Vol/pi²=1/8；(e0,e1,e2,(1,1,1,1)/2) 有 18 室、Vol/pi²=1/32。
  交换两顶点只改变有向量；非成员和 det=0 明确拒绝。
- [x] 实现几何：整数坐标表示 Hurwitz 点；枚举 C(24,4)，用 24 个顶点排列后的 Gram 键最小值分类。
  秩/行列式用精确整数；所有非退化面法向做 gcd 归一化，必须属于 F4 的 24 条法线。
  从严格位于基本室的探针 (8,3,2,1)，用下列四反射闭包得到 1152 室内点：

```python
s1(x) = (x[0],x[2],x[1],x[3])
s2(x) = (x[0],x[1],x[3],x[2])
s3(x) = (x[0],x[1],x[2],-x[3])
s4(x) = x - (x[0]-x[1]-x[2]-x[3])/2 * (1,-1,-1,-1)
```

  每个室内点以 V^-1 p 的四个严格正号判定是否属于正锥；体积为室数*pi²/576。
  基本室/反射铺砌的证明单列，不能仅凭点数推断体积。
