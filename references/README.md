# 参考材料

`2510.14722v2-译文在左.pdf` 是用户提供的中英对照参考件。原论文为 Qiang Jia、Ran Luo、Jiahua Tian、Yi-Nan Wang、Yi Zhang 的 *Anomaly of Continuous Symmetries from Topological Defect Network*，arXiv:2510.14722v2。

正文推导按英文原稿的式 (7)–(14)、附录 C 和 E 核对，并在文稿中明确处理了全局纯规范与二级类提升的适用条件。双语文件的翻译来源未在现有交接材料中注明；本仓库不把译文归为本次研究成果。

数学体积公式引用 Jun Murakami, *Volume formulas for a spherical tetrahedron*, arXiv:1011.2584v4；二级类与连续性讨论引用 Baez–Lauda, *Higher-Dimensional Algebra V: 2-Groups*, arXiv:math/0307200v3。详细参考文献列于 `paper/su2_cocycle.tex` 和 PDF。
